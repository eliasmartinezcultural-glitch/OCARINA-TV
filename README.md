# OCARINA TV

Canal audiovisual local de San Patricio del Chañar.

**V1 — GitHub Pages**

Ocarina TV reúne programas, historias, personas, cultura, memoria, ruralidad y territorio en una plataforma audiovisual local.

## Arquitectura V1
- Sitio estático, sin backend.
- GitHub Pages como alojamiento.
- Videos externos (YouTube) para evitar almacenar archivos pesados en GitHub.
- Estructura preparada para ampliar catálogo y programación.

## Publicación
El despliegue se realiza mediante GitHub Actions y GitHub Pages.
